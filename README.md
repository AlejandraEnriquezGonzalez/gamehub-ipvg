
# GameHub IPVG

## Descripción

GameHub IPVG es una plataforma web destinada a la organización y gestión de torneos internos de videojuegos y eSports del Instituto Profesional Virginio Gómez.

## Objetivo

Facilitar el registro de estudiantes, la creación de equipos, las inscripciones a torneos, la programación de partidos, el registro de resultados oficiales y la visualización de rankings.

## Tecnologías

- Vue 3
- Vite
- Vue Router
- NestJS
- TypeORM
- MySQL
- Swagger
- Git y GitHub
